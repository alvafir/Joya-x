# JOYA Enterprise 4.2.0 STABLE

Versión completa y estable para la rama principal de GitHub.

## Incluye

- API Manager
- Scanner de partidos por fecha
- League Intelligence Center
- Match Center
- Probability MVP de API-Football
- Probability Engine JOYA
- Confianza, calidad de fuente, riesgo y estado
- Regla NO BET cuando la evidencia es insuficiente

## Instalación

1. Descomprime el ZIP.
2. Sube todo el contenido a la rama `principal`.
3. Reemplaza los archivos existentes.
4. Mantén `app.py` como archivo principal en Streamlit.
5. Conserva los mismos Secrets.

Esta versión queda congelada como respaldo estable antes de continuar el desarrollo en la rama `dev`.
